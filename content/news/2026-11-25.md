+++
title = "The Linux Foundation主催「Open Source Summit Japan 2026」登壇"
+++

2026年12月7日(月)～ 12月9日(水) の3日間にわたり開催される[Open Source Summit Japan 2026][1]にて、弊社メンバー3名が登壇いたします。

本カンファレンスは、Zephyr RTOSや組込み技術に関する最新ノウハウが集まるグローバルイベントです。

この度、弊社から提出した計4つのセッションが採択されました。

宇宙機開発の実践環境における[Zephyr][2]の活用事例や、信頼性・安全性を高める検証手法などをテーマに発表を行う予定です。

会期中、[虎ノ門ヒルズフォーラム][7]（またはオンライン）で皆様とお会いできることを楽しみにしております。

### 登壇セッション概要

#### 1. 荘司 靖 (Yasushi Shoji)

**セッション1**
- **登壇日時:** 2026年12月8日（火）14:50 - 15:30
- **場所:** ホールB3 (4F)
- **タイトル:** [SEE Fault Injection and Mitigation Testing With Zephyr][3]

**セッション2**
- **登壇日時:** 2026年12月9日（水）10:50 - 11:30
- **場所:** ホール B3 (4F)
- **タイトル:** [From Documentation to Detectors: Making Zephyr API Contracts Machine-Checkable][4]

#### 2. 佐々木 拓也 (Takuya Sasaki)
- **登壇日時:** 2026年12月8日（火）16:40 - 17:20
- **場所:** ホール B3 (4F)
- **タイトル:** [Zephyr OTA Updates in Practice: Lessons Learned From Spacecraft Development][5]

#### 3. 安藤 匠 (Takumi Ando)
- **登壇日時:** 2026年12月9日（水）11:40 - 12:20
- **場所:** ホール B3 (4F)
- **タイトル:** [Where Should Zephyr's RAM Live? TCM, DMA, OCM, and TF-A on AMD Versal][6]

### 開催概要

- **イベント名:** Open Source Summit Japan 2026
- **会期:** 2026年12月7日(月)～ 12月9日(水)
- **開催地:** [虎ノ門ヒルズフォーラム(虎ノ門ヒルズ 森タワー5階)][7]
- **主催:** [The Linux Foundation][8]
- **公式ページ:** [Open Source Summit Japan][1]
